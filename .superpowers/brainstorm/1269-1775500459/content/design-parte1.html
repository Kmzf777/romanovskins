1. Mudanças no Schema do Banco

Precisamos de 3 novos campos na tabela raffles para suportar o sorteio e o histórico real:

-- Adicionar à tabela raffles:
ALTER TABLE raffles ADD COLUMN drawn_at TIMESTAMPTZ;
ALTER TABLE raffles ADD COLUMN winner_ticket_number INT;
ALTER TABLE raffles ADD COLUMN winner_user_id UUID REFERENCES users(id);

-- Status 'drawn' precisa ser adicionado ao CHECK:
-- active → closed → drawn
⚠️ O schema atual tem status active/closed/cancelled mas o código já usa drawn em vários lugares. Vamos padronizar: active → closed → drawn
