🚨 Crítico — Quebrado ou Faltando (MVP não está completo)

❌ Mecanismo de Sorteio
Admin não tem como realizar um draw. Não há como escolher vencedor, fechar rifa nem registrar resultado.
❌ Ganhadores — Dados Falsos
getRecentWinners() SEMPRE retorna mock hardcoded, mesmo com DB configurado. Nunca mostra dados reais.
❌ Timer de 20min no Checkout
A reserva expira em 20min mas o usuário não vê nenhum contador. Pode deixar expirar sem saber.
❌ pg_cron não configurado
O cron que libera reservas expiradas está comentado no PRD. Sem ele, tickets reservados ficam presos para sempre.
❌ Transaction ID no Success
A página de sucesso usa ?tid= mas payment-actions.ts não passa o ID na returnUrl. Comprovante sempre fica sem dados.
❌ Cotas Restantes — Mock
No card da rifa, "Cotas Restantes" é Math.floor(total * 0.4). Nunca reflete o real.
❌ Float/Condição — Mock
Float "0.01231234135" e "Field-Tested" são hardcoded no ticket-card. Não vem do banco.
❌ Admin sem Gestão de Rifas
Dashboard mostra "--" em todos os stats. Não tem listagem, edição nem encerramento de rifas.
❌ Metadata do Site
Title/description do layout.tsx ainda é "Create Next App". Péssimo para SEO e compartilhamento.
